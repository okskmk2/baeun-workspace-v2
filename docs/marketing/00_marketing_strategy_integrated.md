# 바은 워크스페이스 마케팅 전략 통합 문서

작성일: 2026-09-20
제품: 바은 워크스페이스

## 1. 핵심 결론

바은 워크스페이스는 단순한 협업 도구가 아니라, 작은 팀의 업무 구조를 정리하는 운영 플랫폼입니다.

가장 중요한 경쟁력은 다음입니다.

- 팀 공간과 업무 공간을 분리한다.
- 문서, 할 일, 대화, 데이터를 같은 프로젝트 안에서 사용한다.
- 필요한 자리만 추가하고, 사용한 만큼만 결제한다.

즉, 바은은 “기능을 많이 모은 올인원 SaaS”보다 “같은 맥락에서 일하는 구조”를 만드는 제품으로 포지셔닝해야 합니다.

## 2. 시장 포지셔닝

현재 팀은 보통 아래 도구를 함께 사용합니다.

- 문서: Notion, Google Docs
- 작업 관리: Jira, Trello, ClickUp
- 커뮤니케이션: Slack, Discord
- 표/데이터: Airtable, Excel, Notion DB

문제는 이 도구들이 같은 맥락을 공유하지 않는다는 점입니다. 같은 프로젝트를 진행해도 문서는 문서, 업무는 보드, 결정은 채팅, 데이터는 시트로 흩어지게 됩니다.

바은은 이 흐름을 프로젝트 단위로 묶습니다.

### 포지셔닝 문장
- 팀 공간과 업무 공간을 나누어 운영합니다.
- 문서가 일로 이어지고, 일이 대화와 연결됩니다.
- 필요한 자리만 매달 결제합니다.

### 경쟁 프레임
- Notion 대비: 문서 중심에서 벗어나 작업·대화·데이터가 같은 프로젝트 안에 있음
- Jira 대비: 업무를 문서와 의사결정 흐름과 함께 운영
- Slack 대비: 업무 대화가 실제 프로젝트와 연결됨

## 3. 타깃 고객

### 1차 타깃
5~30명 규모의 소규모 팀

### 대표 페르소나
- 팀 리드 / PM
- 워크스페이스 관리자 / 운영 담당
- 실무 멤버

### 고객의 불편함
- 문서, 작업, 대화, 데이터가 서로 다른 툴에 흩어짐
- 매번 어떤 툴을 써야 할지 고민함
- 팀 운영과 비용 구조를 정리하기 어려움

### 고객의 기대
- 탭 전환 없이 계속 일하고 싶음
- 팀의 맥락이 끊기지 않길 원함
- 필요한 자리만 과금하고 싶음

## 4. 메시지 전략

마케팅 메시지는 한 번에 여러 의미를 담지 않고, 반복해야 합니다.

### 메시지 기둥
1. 팀 공간과 업무 공간을 나눈다.
2. 문서, 작업, 대화가 같은 프로젝트 안에 있다.
3. 필요한 자리만 매달 결제한다.

### 추천 헤드라인
- 문서, 할 일, 대화를 한곳에서 사용합니다.
- 팀 공간과 업무 공간을 나눴습니다.
- 탭을 바꾸지 말고, 이어서 일하세요.
- 사용한 자리만 매달 결제합니다.

### 랜딩용 문장 예시
- 문서, 할 일, 대화를 한 프로젝트에서 사용합니다.
- 워크스페이스와 프로젝트를 나눠 팀을 관리하고, 일은 한곳에서 진행합니다.
- 필요한 자리만 매달 결제합니다.

## 5. 카피 원칙과 금지 표현

### 권장 톤
- 짧고 분명함
- 현재형
- 실제로 하는 일만 말함
- 문제·해결 구조로 설명함

### 피해야 할 표현
- 무료 플랜
- 팀 플랜
- 올인원 혁신
- 무제한
- 엔터프라이즈급
- AI가 프로젝트를 대신 운영한다
- 완전 대체라는 과장 표현

## 6. 채널 전략

### 웹사이트 랜딩
- 문제 제기: 도구가 늘고 맥락이 끊긴다
- 해결책: 워크스페이스와 프로젝트 분리
- 기능 요약: 위키, 칸반, 채널, 데이터
- 요금 설명: 필요한 자리만 사용한 만큼 결제
- CTA: 시작하기 / 요금 보기

### SNS
- 문제 제시형 콘텐츠
- 비교형 콘텐츠
- 팀 운영 구조 설명형 콘텐츠
- 짧은 광고형 메시지

### 이메일
- 문제를 먼저 말함
- 구조를 설명함
- 요금 구조를 전달함
- CTA로 전환

### 영업 자료
- 팀장 관점으로 설명
- 운영자 관점으로 설명
- 실무자 관점으로 설명

## 7. KPI와 로드맵

### 핵심 KPI
- 랜딩 페이지 방문 수
- CTA 클릭률
- 요금 페이지 체류 시간
- 가입 신청률
- 승인 후 활성 사용자 비율

### 우선순위 로드맵
1. 메시지 고정
2. 랜딩 구조 개선
3. SNS 콘텐츠 제작
4. 이메일/소개 자료 제작
5. 전환 최적화와 유지 개선

## 8. 최종 추천 메시지

바은 워크스페이스는 작은 팀이 문서, 작업, 대화, 데이터를 한 프로젝트에서 쓰기 위한 협업 공간입니다.
조직과 멤버는 워크스페이스에서 관리하고, 실제 업무는 프로젝트에서 진행합니다.
필요한 자리만 매달 결제하는 구조로 더 단순하게 운영할 수 있습니다.

## 9. 결론

바은의 마케팅은 기능을 많이 팔기보다, 팀의 업무 구조를 정리해주는 솔루션으로 설계해야 합니다.

이 전략이 제대로 자리 잡으면 제품의 차별점은 단순한 기능 묶음이 아니라, 팀이 같은 맥락 안에서 일하게 만드는 구조적 경쟁력으로 확립됩니다.
