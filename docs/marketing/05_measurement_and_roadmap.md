# 5단계: KPI와 실행 로드맵

작성일: 2026-09-20
제품: 바은 워크스페이스

## 1. 목표

마케팅은 기능 소개가 아니라 전환을 달성하는 활동이어야 합니다. 따라서 KPI는 다음을 기준으로 설정합니다.

- 랜딩 페이지 체류 시간
- 요금 페이지 클릭률
- 가입 신청률
- 승인 후 실제 활성 사용자 비율
- 반복 사용률과 유지율

## 2. 핵심 KPI

### A. 인지 단계
- 랜딩 페이지 방문 수
- 페이지 체류 시간
- CTA 클릭률

### B. 이해 단계
- 요금 페이지 방문 수
- 요금 이해 시간
- 워크스페이스/프로젝트 설명 섹션 체류

### C. 전환 단계
- 시작하기 버튼 클릭 수
- 신청 완료 수
- 승인 완료 수
- 유료 전환 수

## 3. 성공 기준

### 초반(1개월)
- 랜딩 페이지에서 핵심 메시지 이해가 이루어짐
- 팀장/운영자 타깃의 CTA 클릭률이 높음
- 요금 페이지에서 최소 20~30% 이상의 사용자 관심 유지

### 중기(3개월)
- 팀 수준의 유입이 증가
- 승인 후 로그인 사용자 수가 꾸준히 유지됨
- 비교적 단순한 구조 설명이 실제 문의로 이어짐

### 장기(6개월)
- 소규모 팀 대상 도입 성공 사례 누적
- 반복 추천과 워드 오브 마우스 형성
- 팀 운영 구조 설명형 마케팅이 표준화됨

## 4. 실행 로드맵

### 1단계: 메시지 고정
- 포지셔닝 문장 3개 정리
- 헤드라인 5개 확정
- 금지 표현 정리

### 2단계: 랜딩 개선
- 문제-해결-기능-요금 구조 반영
- CTA 배치 최적화
- 비교 프레임 정리

### 3단계: 유입 콘텐츠 제작
- SNS 10개 이상 제작
- 팀장용/운영자용 소개글 작성
- 이메일 시나리오 구성

### 4단계: 전환 최적화
- 가입 플로우 개선
- 승인 후 온보딩 메시지 작성
- 고객 피드백 수집

### 5단계: 성장 루프
- 도입 사례 수집
- 한 줄 후기 제작
- 사용자 언어를 마케팅 문구에 반영

## 5. 필수 원칙

- 기능 나열을 줄이고 업무 구조를 설명한다.
- 요금은 단순하고 명확하게 설명한다.
- 자주 쓰는 문구를 기준으로 메시지를 통일한다.
- 실제 사용자가 말하는 표현을 마케팅 문구에 활용한다.

## 6. 최종 결론

바은 워크스페이스의 마케팅은 “저렴한 협업 도구”를 파는 방식이 아니라, “팀이 같은 맥락에서 일하도록 구조를 정리하는 도구”로 설계해야 합니다.

이 전략이 안정적으로 자리 잡으면, 기능 중심의 경쟁에서 벗어나 구조 중심의 차별화를 만들 수 있습니다.
