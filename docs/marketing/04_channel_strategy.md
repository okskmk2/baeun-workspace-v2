# 4단계: 채널 전략과 실행 계획

작성일: 2026-09-20
제품: 바은 워크스페이스

## 1. 목표

바은 워크스페이스는 “기능 소개”보다 “팀 운영 구조를 정리하는 해결책”으로 홍보해야 합니다.

그 목표를 가장 잘 충족하는 채널은 다음과 같습니다.

- 웹사이트 랜딩
- SNS 콘텐츠
- 이메일/도입 제안
- 커뮤니티/네트워킹
- 영업용 설명 자료

## 2. 채널별 전략

### 웹사이트 랜딩

가장 우선순위가 높은 채널입니다.

필수 구성 요소:
- 문제 제기: 도구가 늘고 맥락이 끊긴다
- 해결책: 워크스페이스와 프로젝트 분리
- 기능 요약: 위키, 칸반, 채널, 데이터
- 요금 설명: 필요한 자리만 사용한 만큼 결제
- CTA: 시작하기 / 요금 보기

### SNS

추천 포맷:
- 문제 제시형 콘텐츠
- 비교형 콘텐츠
- 팀 운영 구조 설명형 콘텐츠
- 짧은 메시지 광고

예시:
- 같은 팀인데 문서·업무·대화가 다른 툴에 흩어져 있나요?
- 바은 워크스페이스는 한 프로젝트에서 그 흐름을 이어줍니다.

### 이메일

주 목적은 리드 유치와 도입 설명입니다.

구성:
1. 팀이 겪는 문제
2. 바은이 제안하는 구조
3. 기능 요약
4. 사용한 만큼 결제하는 구조
5. CTA

### 영업/소개 자료

영업 담당자가 자주 쓰는 문장은 다음과 같습니다.

- 같은 팀이 도구마다 다른 맥락을 쓰면 실행이 느려집니다.
- 바은은 문서, 할 일, 대화, 데이터를 한 프로젝트에 붙였습니다.
- 조직과 비용은 워크스페이스에서 관리하고, 업무는 프로젝트에서 진행합니다.

## 3. 퍼널 설계

### 단계 1: 인지
- 브랜드/정체성 노출
- 문제 인식 유도
- 짧은 메시지로 관심 확보

### 단계 2: 이해
- 랜딩 페이지에서 구조 설명
- 요금 페이지에서 비용 구조 설명
- 팀이 겪는 문제를 구체화

### 단계 3: 검증
- 데모, 안내, 유스케이스 설명
- 가입 전 질문 답변
- 워크스페이스/프로젝트 구조 이해

### 단계 4: 전환
- 시작하기
- 요금 보기
- 신청 후 승인 프로세스 안내

## 4. 운영 방식

- 랜딩 문장은 3개 핵심문장으로 고정한다.
- SNS는 문제-해결-구조형 순으로 제작한다.
- 이메일은 기능 소개보다 팀 운영 문제를 먼저 말한다.
- 영업 자료는 고객별 관점으로 달라진다.

## 5. 우선 실행 우선순위

### 가장 먼저 해야 할 것
1. 랜딩 헤드라인 정리
2. 요금 구조 문구 정리
3. 5개 SNS 카피 큐레이션
4. 소개 자료 1페이지 제작

### 다음 순서
1. 이메일 시나리오 제작
2. 영업용 데모 스크립트 작성
3. 광고 문구 기반 테스트

## 6. 핵심 메시지 반복 원칙

아래 문장을 채널별로 변형해 사용합니다.

- 팀 공간과 업무 공간을 나눴습니다.
- 문서, 할 일, 대화를 한 프로젝트에서 사용합니다.
- 필요한 자리만 매달 결제합니다.

## 7. 결론

마케팅 성공의 핵심은 도구를 팔기보다 팀 운영 구조를 정리해주는 솔루션으로 보여주는 것입니다.

바은은 팀의 업무 흐름을 연결해 주는 제품이므로, 채널 전략도 흐름 중심으로 설계해야 합니다.
