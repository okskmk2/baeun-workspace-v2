# 퍼블릭 랜딩 페이지 마케팅 문구 정리

작성일: 2026-05-19

## 1) 분석 기준

프로젝트 사이트와 워크스페이스 사이트의 실제 기능/문구를 바탕으로 퍼블릭 랜딩 페이지용 제품 홍보 문구를 정리했다.

- 프로젝트 영역 핵심: 위키, 작업 보드(칸반/백로그/간트), 채널, 데이터, 프로젝트 설정
- 워크스페이스 영역 핵심: 프로젝트 허브, 멤버/프로젝트 관리, 라이선스/결제, 게시판, 랭킹

## 2) 랜딩 핵심 메시지 (Value Proposition)

### 메인 한 줄

- 탭 전환 없이, 문서-업무-대화를 하나의 흐름으로 연결하는 팀 운영 플랫폼

### 서브 문구

- 위키에서 정리한 맥락이 보드의 실행으로 이어지고, 채널의 대화가 다시 기록으로 남습니다.
- 워크스페이스 단위의 멤버, 권한, 라이선스, 결제까지 한 곳에서 운영할 수 있습니다.

## 3) Hero 카피 후보

### Hero 조합 A

- 헤드라인: 기획부터 실행, 소통까지 한 번에 이어지는 협업 흐름
- 보조문구: 위키-칸반-채널이 유기적으로 연결되어 팀이 맥락을 잃지 않고 빠르게 결정합니다.
- CTA 1: 워크플로우 시작하기
- CTA 2: 도입 사례 보기

### Hero 조합 B

- 헤드라인: 문서가 작업이 되고, 작업이 성과가 되는 공간
- 보조문구: 백로그 드래그 앤 드롭, 간트 일정 가시화, 채널 연동으로 실행 속도를 높이세요.
- CTA 1: 무료로 시작하기
- CTA 2: 기능 둘러보기

### Hero 조합 C

- 헤드라인: 팀 운영에 필요한 모든 관리, 하나의 워크스페이스에서
- 보조문구: 멤버 초대, 프로젝트 관리, 라이선스 슬롯, 결제 상태까지 운영 관점을 통합합니다.
- CTA 1: 워크스페이스 만들기
- CTA 2: 플랜 확인하기

## 4) 셀링 포인트 (USP) 문구

### USP 1. Trinity Flow

- 카피: 지식 베이스, 작업 보드, 메시징 채널을 하나의 루프로 연결
- 설명: 문서 작성, 업무 실행, 팀 소통이 분리되지 않아 맥락 손실을 줄입니다.

### USP 2. 실행 중심 프로젝트 운영

- 카피: 백로그에서 보드로, 보드에서 일정으로 이어지는 실행 체계
- 설명: 미할당 작업을 드래그 앤 드롭으로 배치하고 간트로 일정을 읽기 쉽게 확인합니다.

### USP 3. 대화와 업무의 연결

- 카피: 채널 메시지와 이슈를 연결해 결정 근거를 보존
- 설명: 작업 채널, DM, 공지 채널, 보관함까지 지원해 협업 기록을 체계적으로 관리합니다.

### USP 4. 데이터 운영 내재화

- 카피: 워크스페이스 표준 자산과 프로젝트 로컬 데이터를 동시에 관리
- 설명: 행 추가/수정/삭제, 히스토리 확인, TSV 다운로드로 데이터 작업을 빠르게 처리합니다.

### USP 4-1. 프로젝트 데이터 테이블

- 카피: 프로젝트 안에서 바로 쓰는 실무형 데이터 테이블
- 설명: 테이블별 목록 뷰와 버전 정보를 기준으로 데이터를 운영하고, 설정 화면에서 스키마 변경까지 처리합니다.

### USP 5. 워크스페이스 거버넌스

- 카피: 멤버, 프로젝트, 권한, 라이선스, 결제를 한 화면에서 통합 관리
- 설명: 운영자가 리소스 과부족을 즉시 파악하고 필요한 구매/조정을 빠르게 진행할 수 있습니다.

### USP 6. 팀 활력 가시화

- 카피: 프로젝트 우선순위와 구성원 기여를 지표로 확인
- 설명: 프로젝트 허브, 랭킹, 게시판을 통해 팀 상태와 활동 흐름을 한눈에 파악합니다.

## 5) 랜딩 섹션별 문구 초안

### 섹션: 문제 인식

- 문서, 업무, 메시지가 흩어져 있으면 팀은 같은 주제를 여러 번 설명해야 합니다.
- 바은 워크스페이스는 분절된 도구 사이의 왕복을 줄여 결정과 실행의 지연을 줄입니다.

### 섹션: 해결 방식

- 위키에서 기준과 맥락을 정리합니다.
- 칸반/백로그/간트에서 실행 우선순위와 일정을 운영합니다.
- 채널에서 논의와 피드백을 남기고, 기록을 다음 액션으로 연결합니다.
- 데이터 테이블에서 표준 자산과 프로젝트 로컬 데이터를 편집하고 즉시 공유합니다.

### 섹션: 프로젝트 데이터 테이블 상세

- 헤드라인: 팀이 바로 다루는 데이터, 프로젝트 컨텍스트 안에서 끝내기
- 보조문구: 워크스페이스 표준 자산과 프로젝트 임시 테이블을 함께 탐색하고, 행 단위 편집부터 이력 확인까지 한 흐름으로 처리합니다.
- 포인트 1: 테이블별 버전/뷰(목록 중심)로 현재 데이터 상태를 명확히 파악
- 포인트 2: 행 추가/수정/삭제, TSV 다운로드, 변경 이력 확인으로 실무 작업 속도 향상
- 포인트 3: 테이블 설정에서 이름 변경, 컬럼 추가/삭제/순서 변경, 스냅샷 생성 지원
- 포인트 4: 프로젝트 로컬 테이블을 워크스페이스 자산으로 승격 신청해 재사용 기반 확대
- CTA: 데이터 테이블 열기
- Supporting Copy: 테이블 권한 기반으로 생성/수정/삭제 가능 범위를 제어해 안정적으로 협업합니다.

### 섹션: 운영자 관점

- 워크스페이스에서 프로젝트 현황, 멤버 관리, 슬롯/라이선스 상태를 통합 확인합니다.
- 결제/영수증 흐름까지 연결해 팀 확장과 비용 관리를 단순화합니다.

### 섹션: 행동 유도

- Primary CTA: 지금 워크스페이스 시작
- Secondary CTA: 우리 팀에 맞는 플랜 보기
- Supporting Copy: 첫 워크스페이스 생성 후 바로 프로젝트를 열고 운영 흐름을 확인해보세요.

## 6) 짧은 광고성 문구 묶음 (배너/카드용)

- 문서-업무-대화를 하나로, 탭 전환 없는 몰입 협업
- 백로그부터 간트까지, 실행 속도가 보이는 프로젝트 관리
- 메시지가 기록이 되고 기록이 실행이 되는 팀 커뮤니케이션
- 멤버/프로젝트/라이선스/결제를 한 번에 관리하는 워크스페이스 운영
- 팀의 기여와 프로젝트 건강도를 지표로 확인하는 운영 대시보드
- 프로젝트 데이터 테이블에서 편집, 이력, 스키마 관리까지 한 번에

## 7) 근거로 확인한 주요 화면

- 프로젝트 라우팅: 위키/칸반/채널/데이터/설정
- 워크스페이스 라우팅: 프로젝트/게시판/랭킹/설정
- 퍼블릭 홈 메시지: 위키-칸반-채널 연결, AI 인사이트 강조
- 워크스페이스 설정: 멤버 초대/권한, 프로젝트 관리, 라이선스/결제 이동
- 데이터 화면: 표준 자산/프로젝트 로컬 구분, 행 편집, 다운로드
