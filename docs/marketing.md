# 바은 워크스페이스 마케팅 문서

작성일: 2026-09-20  
제품: 바은 워크스페이스 (Baeun Workspace)  
사이트: https://workspace.baeun.com  
언어: 한국어 우선, 영문은 사이트 병기용

이 문서는 랜딩, 요금 페이지, SNS, 소개서, 영업 한 장에 쓰는 메시지와 카피를 한곳에 둔다. 구현되지 않은 기능을 약속하지 않는다. 문구 초안만 모은 파일은 `docs/public_landing_marketing_copy.md`다.

---

## 1. 한 줄

문서, 할 일, 대화, 데이터를 프로젝트 한곳에서 쓰고, 팀 운영은 워크스페이스에서 하는 협업 공간. 사용한 자리만 매달 결제한다.

영문: Documents, tasks, conversations, and data live in one project. The team lives in a workspace. You pay each month only for the seats you open.

## 2. 포지셔닝

### 무엇을 대체하는가

Notion + Jira(또는 칸반 보드) + Slack + 시트 일부를 **프로젝트 하나**로 붙인다. 조직의 멤버·권한·결제는 그 위 **워크스페이스**에 둔다.

대체 문장이 아니다. “다 들어 있는 올인원”보다 **같은 일을 설명하러 탭을 바꾸지 않는다**가 핵심이다.

### 포지션 문장

| 듣는 사람 | 문장 |
| --- | --- |
| 팀 리드 | 기획이 위키에 남고, 실행이 보드로 가고, 결정이 채널에 남는 한 공간입니다. |
| 운영자 | 멤버, 프로젝트, 슬롯을 워크스페이스에서 보고, 자리는 필요한 만큼만 삽니다. |
| 실무자 | 문서 보고, 일 옮기고, 같은 맥락에서 대화합니다. |

### 경쟁 프레임 (외부 비교에 쓸 때)

| 상대 | 바은이 말하는 차이 | 말하지 말 것 |
| --- | --- | --- |
| Notion | 문서로 끝나지 않고 보드·채널·표가 같은 프로젝트에 있다 | “노션을 대체한다”만 단독으로 |
| Jira / 보드 툴 | 이슈가 문서·대화와 떨어져 있지 않다 | 엔터프라이즈 이슈 트래커 수준 |
| Slack / 메신저 | 대화가 태스크·문서에 붙는다. 공지는 채널 관리자만 | 슬랙 수준의 통합·앱 마켓 |
| 시트 / Airtable | 프로젝트 안에서 표를 바로 다룬다 | 분석·차트·폼이 완성됐다 |
| 묶음 요금제 SaaS | 플랜 이름이 없다. 자리만 산다 | Free / Team / Business / Enterprise |

## 3. 누구를 설득하는가

1차 고객은 **5~30명 규모 팀**이다. 도구가 이미 여럿이고, 같은 주제를 위키·보드·채팅에 각각 적는 팀.

| 페르소나 | 고통 | 원하는 결과 | 첫 CTA |
| --- | --- | --- | --- |
| 팀 리드 / PM | 맥락이 툴마다 끊긴다 | 한 프로젝트에서 결정·실행이 보인다 | 시작하기 |
| 워크스페이스 운영자 | 좌석·프로젝트를 플랜에 맞춰 짜야 한다 | 필요한 자리만 늘린다 | 요금 보기 |
| 실무 멤버 | 어디에 쓸지 매번 고른다 | 위키·칸반·채널이 한 GNB | 시작하기 |

가입은 어드민 승인 후 로그인된다. 마케팅에서 “가입 즉시 팀 전원 접속”이라고 쓰지 않는다. “신청 후 승인되면 시작한다”가 정확하다.

## 4. 메시지 기둥

세 문장만 반복한다. 채널이 달라도 이 순서를 지킨다.

1. **팀 공간과 일터를 나눴다.** 워크스페이스는 멤버와 조직, 프로젝트는 위키·칸반·채널·데이터.
2. **네 도구가 한 프로젝트에 있다.** 문서가 일이 되고, 일이 대화와 붙는다.
3. **요금제는 없다.** 워크스페이스·프로젝트·멤버 자리를 넘는 분만 매달 낸다.

보조 기둥 (필요할 때만):

- 슬롯이 부족해도 이미 만든 조직·사람·일은 지우지 않는다. 새로 여는 행위만 막는다.
- 프로젝트 안에서 AI가 맥락을 찾고, 위키를 표로 옮기는 실행을 도울 수 있다. “완전 자동 운영”은 쓰지 않는다.

## 6. 가격을 말할 때

표시 단가 근거는 프론트 계산기 상수(`frontend/src/constants/pricing.js`)다. 결제 화면의 확정가는 스토어 카탈로그가 우선이다. 광고에 단가를 박을 때는 “스토어 기준, 변동 가능”을 붙인다.

| 항목 | 무료 | 넘는 분 (월, 표시가) |
| --- | --- | --- |
| 워크스페이스 | 1 | $10 / 조직 |
| 프로젝트 | 워크스페이스당 3 | $3 / 프로젝트 |
| 멤버 | 워크스페이스당 5 (소유자 포함) | $1 / 좌석 |
| 저장 | 워크스페이스당 5GB | $0.10 / GB |

반드시 말할 것:

- 멤버 자리는 계정 전체가 아니라 **그 워크스페이스의 자리**다.
- 저장 5GB는 팀 전체가 아니라 **워크스페이스마다**다. 남은 용량을 다른 팀으로 옮기지 않는다.
- 한도를 넘어도 파일·프로젝트·멤버를 삭제하지 않는다. 새로 만드는 작업만 제한한다.
- 나중에 산 자리는 새 구독이라 결제일이 합쳐지지 않는다.

금지 표현:

- 무료 플랜, 팀 플랜, 비즈니스 플랜, 엔터프라이즈
- 추천 플랜 배지, 연간 티어 비교표
- 공용 스토리지 풀
- 위키·칸반·채널·데이터를 플랜별로 잠근다는 말
- “로그인하면 바로 칸반” (착지는 위키, 가입은 승인 후)

## 7. 기능 카피 (캠페인용)

홈보다 한 단계 구체화할 때 쓴다. 게시판·랭킹·데이터 차트/폼은 아직 얇으니 메인 약속에 넣지 않는다.

### 위키

- 짧은: 기준과 맥락을 페이지로 남깁니다.
- 긴: 페이지 트리와 파일, 페이지별 편집 권한. 보기만 되는 사람은 편집을 신청합니다.

### 칸반

- 짧은: 보드, 백로그, 일정을 한 일감으로 봅니다.
- 긴: 미할당 일을 보드로 옮기고, 담당·마감이 있는 태스크가 채널과 이어집니다.

### 채널

- 짧은: 공지, 일상, 업무 대화를 나눕니다.
- 긴: 이슈에 붙는 업무 채널이 있어, 결정이 채팅에만 묻히지 않습니다. 공지는 관리자만 씁니다.

### 데이터

- 짧은: 프로젝트 안에서 표를 다룹니다.
- 긴: 워크스페이스 표준 자산과 프로젝트 로컬 테이블을 같이 보고, 행을 고치고 내려받습니다.

### AI (보조, 전면에 두지 않음)

- 프로젝트 맥락을 묻고, 위키에서 표를 만들어 데이터 메뉴로 옮기는 실행을 미리보기한 뒤 승인받아 진행할 수 있습니다.
- “AI가 프로젝트를 대신 운영한다”, “무제한 AI”는 쓰지 않는다.

## 8. 채널별 카피 뱅크

### 헤드라인 후보 (광고·히어로 교체용)

한국어

- 문서, 할 일, 대화를 한곳에서 사용합니다. *(현재 홈)*
- 팀 공간과 업무 공간을 나눴습니다.
- 탭을 바꾸지 말고, 이어서 일하세요.
- 사용한 자리만 매달 결제합니다.
- 문서가 일이 되고, 일이 대화와 만납니다.

English

- Use documents, tasks, and conversations in one place.
- Team space and work space are separate.
- Don’t switch tabs. Keep going.
- Pay each month only for the seats you open.

### SNS / 짧은 광고

1. 위키에서 정리하고, 칸반에서 움직이고, 채널에서 결정합니다. 바은 워크스페이스.
2. 요금제 고르지 마세요. 팀 하나, 프로젝트 셋, 멤버 다섯까지는 바로 시작합니다.
3. 노션은 문서, 보드는 일, 슬랙은 말. 바은은 그 셋을 프로젝트에 붙입니다.
4. 자리가 모자라도 팀을 지우지 않습니다. 새로 여는 것만 막습니다.
5. Documents, tasks, and talk. One project. Pay for the seats you add.

### 이메일 제목

- 팀 공간과 일터를 나눈 협업 도구
- 위키·칸반·채널·데이터, 프로젝트 하나에서
- 정해진 요금제는 없습니다

본문 골격:

1. 문제 한 줄 (도구가 늘수록 설명이 반복된다)
2. 구조 한 줄 (워크스페이스 / 프로젝트)
3. 네 도구
4. 시작 한도 (1 / 3 / 5)
5. CTA: 시작하기, 보조: 요금 보기

### 소개서 오프닝 (3~4문장)

바은 워크스페이스는 작은 팀이 문서·할 일·대화·표를 한 프로젝트에서 쓰기 위한 협업 공간입니다. 조직의 멤버와 권한, 자리는 워크스페이스에서 관리합니다. 묶음 요금제 없이 워크스페이스·프로젝트·멤버 자리를 넘는 분만 매달 결제합니다. 시작 한도 안이면 결제하지 않습니다.

### 보도용 한 문단

바은 워크스페이스(Baeun Workspace)는 위키, 칸반, 채널, 데이터 테이블을 프로젝트 단위로 묶은 협업 플랫폼이다. 팀 운영(멤버, 게시판, 라이선스)은 워크스페이스에, 실무는 프로젝트에 둔다. 과금은 구독 티어가 아니라 슬롯이며, 기본 허용량을 넘는 조직·프로젝트·좌석과 저장만 월 과금한다.

## 10. 톤과 금지

톤: 짧은 문장, 현재형, 제품이 실제로 하는 일만. 감탄·허들 없는 “혁신” 수사는 쓰지 않는다.

말해야 하는 단어: 워크스페이스, 프로젝트, 위키, 칸반, 채널, 데이터, 슬롯, 자리, 사용한 만큼, 시작 한도.

쓰지 않는 단어: 올인원 혁신, 무료 플랜, 팀 플랜, 시즌 한정, 무제한, 엔터프라이즈급, AI 자율 운영, 탭 전환 제로(절대치).

마케팅에 올리지 않는 것:

- 어드민 콘솔
- 데이터 form / chart (“준비 중” 화면)
- 워크스페이스 게시판·랭킹을 완성된 커뮤니티로 그리는 카피
- 가입 즉시 전원 접속
- Polar 포털에서 구독 수량을 올리라는 안내 (결제일이 합쳐질 수 있음)

브랜드 표기:

- 국문: 바은 워크스페이스
- 영문: Baeun Workspace
- 도메인: workspace.baeun.com
- “바운”, “BAUN”, “바은스페이스”로 쓰지 않는다.

## 11. 퍼널

```
인지 (홈, SNS, 소개서)
  → 이해 (/pricing, 슬롯 계산기)
    → 신청 (/signup)  → 승인 대기
      → 로그인 → 시작 한도 안에서 워크스페이스·프로젝트
        → 한도 초과 시 스토어 (/store, /cart)
```

기본 CTA 쌍: **시작하기** (`/signup`) + **요금 보기** (`/pricing`).  
운영 중 팀에게는 **슬롯 추가** (`/store`) + **내 슬롯** (`/settings/plan`).

공개 프로젝트 목록(`/open-projects`)은 인지 채널로 쓸 수 있다. 유료 전환의 주 경로로 밀지는 않는다.

## 12. 측정 (권장)

캠페인 UTM은 홈·요금·가입에만 붙인다. 스토어는 구매 의도 트래픽으로 따로 본다.

| 단계 | 보는 것 |
| --- | --- |
| 인지 | `/` 방문, 히어로 CTA 클릭 |
| 이해 | `/pricing` 체류, 계산기 조작, 스토어 이동 |
| 전환 | `/signup` 완료, 승인 대기 건수 |
| 활성화 | 첫 워크스페이스, 첫 프로젝트, 위키 첫 페이지 |
| 수익 | 슬롯 종류별 결제, 초과 저장 |

가입 승인 큐가 있으면 “가입 수 = 활성 팀 수”로 보고하지 않는다.
